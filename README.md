# ChatGPT WSL Extension

An approval-based Chrome extension for reviewing and executing shell commands in a WSL workspace.

> **Security:** Commands execute with the permissions of the configured WSL user. Always review the exact command before approving execution.

## Features

- Approval-based shell execution
- ChatGPT command detection
- WSL workspace restrictions
- Local HTTP bridge
- Chrome Native Messaging integration
- Draggable, resizable terminal panel
- No automatic command execution
- No automatic ChatGPT message submission
